One satirical sentence roasting lawmakers who would regulate AI, crypto or the internet but cannot convert a file to PDF. The program writes the line to `/output/entry.txt` — a single sentence, 189 characters, inside the 1–320 gate — and enforces the gate itself before writing.

> The senator who wrote the AI Safety Act just asked his intern to print the bill, scan it, and email it back as a PDF, because converting the file himself felt like letting the machines win.

The setup grants the senator real authority (he wrote the AI Safety Act), then undercuts it with the file he cannot convert; the punch lands on the last few words.

## Run it

```sh
node main.ts
```

Writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Node 22+, stdlib only, deterministic — two runs produce byte-identical output.
